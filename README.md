Планировщик задач

Учебный проект, веб-сервер, для управления списком задач

Написан на языке Go и использует sqlite
Использовалась версия Go 1.25.5

Выполненные задания со звёдочкой:
    - подключена возможность указать порт через переменную TODO_PORT
    - подключение файла базы данных через переменную TODO_DBFILE
    - дополнительные флаги w и m в правилах повторения
    - запуск через докер

Если запускать не через докер:
Для запуска можно выполнить команду go run .
Сервер по умолчанию запускается на порту 7540 и приложение будет доступно по адресу http://localhost:7540
Файл базы данных по умолчанию scheduler.db

Перед запуском тестов необходимо запустить веб-сервер:
go run .
Затем в другом терминале
go test ./tests

команда для запуска через докер: docker compose up --build
